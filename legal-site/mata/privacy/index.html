MATA プライバシーポリシー

制定日: 2026年9月1日
最終改定日: 2026年9月2日

MATAは、TODO、カテゴリ、履歴などの内容をMochisoftsのサーバーへ送信せず、端末内で管理します。 一方、広告、同意管理、祝日情報取得のため、下記の第三者サービスと通信します。

1. 提供者とお問い合わせ先

MATA（以下「本アプリ」）は、個人運営のMochisofts（以下「提供者」）が提供します。 本ポリシーに関するお問い合わせは、 com.mochisofts@gmail.com までお願いします。

2. 端末内で扱う情報

本アプリは、機能提供のため次の情報を利用者の端末内へ保存します。

  • TODOのタイトル、説明、日付、繰り返し、期限、通知設定
  • カテゴリの名称、色、アイコン、並び順
  • 完了、未完了、スキップ、期間結果などの履歴
  • 表示、テーマ、一日の終了時刻、週の開始曜日などの設定
  • 祝日情報のキャッシュと最終更新情報
  • 通知、ウィジェット、バックアップ処理に必要な内部状態

本アプリはアカウント登録、ログイン、クラウド同期、自動バックアップを提供しません。 Android Auto Backupおよび端末間転送からアプリデータを除外します。

3. 外部通信と第三者サービス

サービス 目的 処理され得る情報
Holidays JP 日本の祝日情報の取得 IPアドレス、接続日時、固定User-Agent「MATA」、HTTPキャッシュ情報。TODOやカテゴリの内容は送信しません。
Google Mobile Ads / User Messaging Platform 広告表示、同意管理、不正利用防止、広告品質の測定 IPアドレスから推定されるおおよその位置、端末・アプリ・広告識別子、広告やアプリとの操作、診断情報、同意状態など。TODOやカテゴリの内容を広告リクエストへ含めません。
Google Play / Android vitals アプリ配布、品質・安定性の確認 端末情報、OS、アプリバージョン、クラッシュ、ANR、診断情報など。Google Playの機能として処理されます。
GitHub Pages 本ポリシーおよび利用規約の公開 このWebサイトへのアクセス時のIPアドレス、接続日時、ブラウザ情報など、ホスティングに必要なアクセス情報。

第三者サービスによる情報処理は、各サービス提供者の規約・ポリシーに従います。 本アプリ独自の分析SDKやクラッシュ収集SDKは導入していません。送信され得る情報と停止方法の詳細は、 外部送信に関する公表をご確認ください。

4. 広告と同意

本アプリはGoogle AdMobのバナー広告を表示します。法令またはGoogleの要件により同意が必要な場合、 Google User Messaging Platformを使用して同意画面を表示し、広告リクエストの可否を判断します。

プライバシー設定の再表示が必要な地域・状態では、本アプリの設定画面から広告のプライバシー設定を開けます。

5. 通知とウィジェット

利用者が設定したTODOは、通知本文やホーム画面ウィジェットに表示される場合があります。 ロック画面ではTODOのタイトルや説明を公開表示せず、一般的な通知内容を表示します。 端末を共有している場合は、通知とウィジェットの表示にご注意ください。

6. 手動バックアップ

利用者はStorage Access Frameworkを通じて、保存先を選択して手動バックアップを作成できます。 バックアップにはTODO、説明、カテゴリ、履歴、通知設定、一般設定が含まれる場合があります。 本アプリ独自の暗号化は行わないため、安全な保存先を選択し、利用者の責任で管理してください。 保存先事業者による情報処理は、その事業者の規約・ポリシーに従います。

7. 保存期間と削除

  • 端末内データは、利用者が削除するか、本アプリをアンインストールするまで保持されます。
  • TODOの完全削除では、そのTODOに関連する履歴や内部状態も削除します。
  • 手動バックアップは本アプリのアンインストールでは削除されません。利用者が保存先で削除してください。
  • 第三者サービスが保持する情報は、各サービス提供者の保存・削除方針に従います。

8. 権限

本アプリは主に次の権限・OS機能を利用します。

  • 通知: 指定したTODOを通知するため
  • 正確なアラーム: 利用者が指定した時刻に通知を行うため
  • 起動完了の受信: 再起動後に通知とウィジェットを再構成するため
  • インターネットとネットワーク状態: 祝日、広告、同意のため

通知や正確なアラームを許可しない場合も、TODO管理の基本機能は利用できます。

9. 安全管理

本アプリは平文HTTP通信を禁止し、アプリデータをアプリ専用領域へ保存します。 ただし、端末や通信の安全性を完全に保証するものではありません。OSと本アプリを最新の状態に保ち、 端末の画面ロックなどをご利用ください。

10. 子どもの利用

本アプリは13歳未満の子どもを対象としていません。13歳未満の方は本アプリを利用しないでください。

11. 第三者サービスのポリシー

  • Google プライバシーポリシー
  • Google Mobile Ads SDKのデータ開示
  • Google Play 利用規約
  • Holidays JP API
  • GitHub 一般プライバシー声明

12. 本ポリシーの変更

機能、利用サービス、法令またはGoogle Playの要件変更に応じて、本ポリシーを改定する場合があります。 重要な変更は、本ページまたは本アプリ内の適切な方法でお知らせします。改定後の内容は、 本ページに掲載した時点から適用します。
