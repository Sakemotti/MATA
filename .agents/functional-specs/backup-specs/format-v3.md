# MATA 手動バックアップ形式バージョン3

- 文書状態: 確定
- 最終更新日: 2026-08-27
- 基底仕様: [バックアップ形式バージョン2](format-v2.md)

## 1. 適用範囲

バージョン3は、カテゴリ別の一日の終了時刻を廃止し、アプリ全体の設定へ統一した現行書き出し形式である。バージョン2のZIP構造、繰り返し設定、正規順序、件数、ハッシュ、入力上限および参照整合性を継承する。

- `manifest.json.formatVersion`: `3`
- `manifest.json.minimumReaderVersion`: `3`
- `data.json.formatVersion`: `3`
- 読み込み側はバージョン1～3を受け付ける。

## 2. settingsの変更

`settings.uncategorizedEndHour`を廃止し、同じ位置へ次を出力する。

| フィールド | 型 | 値 |
| --- | --- | --- |
| dayEndHour | integer | 全TODOへ適用する一日の終了時刻、0～23 |

バージョン1・2の`uncategorizedEndHour`は、復元時にバージョン3の`dayEndHour`として引き継ぐ。

## 3. categoriesの変更

カテゴリ要素から`endHour`を削除する。カテゴリは名前、色、アイコン、並び順および作成・更新時点を保持し、論理日境界を持たない。

バージョン1・2を復元する場合、カテゴリ要素の`endHour`は構造と値域を検証したうえで破棄する。全TODOには旧バックアップの`settings.uncategorizedEndHour`を共通終了時刻として適用する。

## 4. 履歴スナップショット

確定済み履歴の`endHour`は削除しない。当時の論理日、期限および表示順を再現するため、保存済みの値をそのまま復元する。

## 5. 受け入れ条件

1. バージョン3で共通終了時刻を欠落なく往復できる。
2. バージョン3のカテゴリへ終了時刻を出力しない。
3. バージョン1・2の共通終了時刻をバージョン3の全TODOへ適用して復元できる。
4. バージョン1・2のカテゴリ終了時刻を現在・未来の計算へ使用せず、確定済み履歴の終了時刻は維持できる。
5. バージョン3をバージョン2までにしか対応しない読込実装へ受け入れさせない。
