# SCR-008 未完了TODO一覧画面仕様

- 文書状態: 確定（USER動作確認済）
- 最終更新日: 2026-10-19
- 対応Issue: [#309](https://github.com/Sakemotti/MATA/issues/309)

## 1. 目的と導線

繰り越し設定を忘れた場合にも、今日と過去の未完了を日付横断で発見し、今日の予定を作り直せる画面とする。ハンバーガーメニューの「未完了TODO」から独立画面として開く。今日のTODO一覧には過去分を持つTODOがある場合だけ件数と「一覧を見る」のコンパクトな入口を表示する。当日進捗へ過去分を混ぜない。

## 2. 表示対象とまとめ方

- 非アーカイブTODOを定義IDごとに1カードへまとめる。同じタイトルでもIDが異なるTODOは統合しない。
- 今日の有効論理日の未完了・繰り越し中と、保存済みの確定未完了履歴を対象とする。
- 回数型は現在期間の残回数と、過去の未達成期間を区別して表示する。期間未達成1件を日数分の未完了へ展開しない。
- 未来予定・完了・スキップ・アーカイブ済み・完全削除済みは含めない。終了日を過ぎた非アーカイブTODOの過去分は含める。
- カードには現在のタイトル・カテゴリ、未完了件数、対象日の範囲、今日の実行対象または残回数を表示する。過去分は対象日を展開し、20件単位で前後のページを確認する。
- カテゴリで絞り込める。「すべてのカテゴリ」とカテゴリ未設定を含む対象カテゴリを用意する。
- カテゴリ表示順、最古の対象日、登録日時、IDの順で安定表示する。

## 3. レイアウト

既存のデイリープランナーと同じページ背景色、カード色、角丸24dp、左右16dp・上下12dp・カード間12dpを使用する。上部に概要・件数・カテゴリ選択のカード、その下にTODOごとのカードを置く。AppBar直下には共通の区切り線を置き、カード全体を一覧としてスクロールする。本文をカード内の小さなスクロール枠に閉じ込めない。広い画面では最大840dp・単一列を維持する。操作は縦に並べて文字拡大時にも折り返しを許容する。

主要画面と共通のナビゲーション、広告同意・失敗時の縮退、広告の固定表示、ドロワー・確認ダイアログ中の広告非表示を適用する。ドロワー・レールの項目が画面高を超えた場合もスクロールして到達できるようにする。

## 4. 今日への再登録

1. カードの「今日への再登録」から既存のTODO登録画面を開く。
2. 最新のタイトル・説明・カテゴリを引き継ぎ、実行日は共通終了時刻に基づく今日、繰り返しなし、終了日なし、期限日・期限時刻なし、通知なし、繰り越しオフを初期値とする。元の履歴・予定を変更しない旨をカードで案内する。
3. 通常の新規登録と同じ入力規則・下書き復元・破棄確認を適用する。利用者は保存前に内容を変更できる。引き継いだ初期値が有効なら、入力を変更しなくても保存できる。入力エラー・読込中・保存中は保存を無効にする。変更せず戻った場合は保存も元の一覧除外も行わず、破棄確認も表示しない。
4. 複数の過去分があっても新しいTODOを1件だけ作る。新規TODOの作成と、元カードで確認した範囲の一覧除外は同じDBトランザクションで確定する。
5. キャンセル・入力エラー・保存失敗では元カードを除外しない。元TODOが削除・アーカイブ済み、または同範囲が処理済みなら保存を拒否し、再読込を案内する。重複タップや再送信で新規TODOを増殖させない。
6. 保存後は未完了一覧へ戻る。新規TODOは今日の実行対象として通常のTODO一覧・ウィジェットへ反映される。

## 5. 未完了TODOに表示しない

- カードの同名ボタンから対象名と影響範囲を確認し、確定した場合だけ今回の未完了分を一覧から除外する。
- 履歴の削除・完了化、元TODOの編集、アーカイブ、今日の一覧やウィジェットからの除去は行わない。
- 対象予定の識別日まで確認済みとしてTODOごとに保存する。通常は元の実行日、回数型の現在期間は期間末日で識別する。同じ繰り越し分や期間が翌日に再表示されないようにする。
- 操作後に発生した新しい予定・期間の未完了は再表示する。表示後に新たに到来した分を古い操作で除外しない。
- 定義編集では確認済み境界を保持し、完全削除ではTODO本体とともに消す。
- 繰り返し条件または実行日を変更した場合は、過去の除外分は維持しつつ、未来の期間末日までの境界を前日までに縮める。回数型から毎日などへ変更した後の新しい実行対象まで、旧期間の境界で隠し続けない。

## 6. 整合性・異常系

履歴は既存の補完処理を共用し、補完中は対象日を除外する操作を無効にする。読み込み・補完失敗時は空一覧を成功扱いせず、再試行を提供する。画面復帰と表示中の定期更新で論理日を再評価する。新規権限・外部SDK・通信先は追加しない。

Room 8→9で確認済み境界のnullable列を追加し、既存値は未設定とする。手動バックアップ形式6で境界を保存・復元し、形式1～5は未設定として取り込む。履歴スナップショットには一覧専用の状態を混ぜない。
