Googleの公式案内では、アプリ準備状況の審査にはサポートされるストアへの公開・リンクが必要である。初回公開前のため実施できない手順がある場合は「一般公開待ち」として公開後の確認へ引き継ぐ。ポリシー違反・不承認・未評価の配信制限と同じ状態だと決めず、表示内容・影響・OWNERの判断を記録する。設定を推測して変更したり、本番広告を試験クリックしたりしない。

公開後は`アプリ`→`すべてのアプリを表示`でMATAの準備状況を確認し、Google Playの公開URLへリンクする。`アプリの設定`→`アプリの確認`とapp-ads.txtの状態を確認し、求められた場合に確認を進める。審査中は広告配信が制限される可能性があるため、公開直後の広告未表示だけでアプリの不具合や承認済みと決めつけない。不要なアプリ再登録・広告ID変更・再ビルドは行わない。
