# SCR-004 カテゴリ管理画面仕様

- 文書状態: 未策定
- 関連仕様: [アプリ全体仕様](../../app-spec.md)

## 目的

TODOを分類するカテゴリの登録、編集、削除、並べ替えを行う画面とする。

## 現時点で確定している範囲

- カテゴリには名前、色、アイコン、一日の終了時刻を設定できる。
- カテゴリは任意の順序に並べ替えられる。
- 一日の終了時刻は1時間単位で設定する。
- カテゴリ削除時は、所属TODOを「カテゴリ未設定」へ移動する。
- 初期状態では「カテゴリ未設定」の区分のみ存在する。

## 詳細仕様

一覧レイアウト、登録・編集UI、色とアイコンの候補、並べ替え操作、削除確認などを今後策定する。
