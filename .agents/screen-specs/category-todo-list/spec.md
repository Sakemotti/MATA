# SCR-007 カテゴリ別TODO一覧画面仕様

- 文書状態: 確定
- 最終更新日: 2026-08-26
- 関連仕様: [アプリ全体仕様](../../app-spec.md)、[TODO一覧画面仕様](../todo-list/spec.md)、[TODO登録・編集画面仕様](../todo-editor/spec.md)、[カテゴリ管理画面仕様](../category-management/spec.md)

## 1. 目的

選択したカテゴリに所属するTODOを実行日へ展開せず定義単位で一覧し、TODO登録・編集画面を開くための独立画面とする。日々の完了操作を行うTODO一覧画面とは役割を分ける。

## 2. 表示経路と遷移

- ハンバーガーメニューの「カテゴリ別TODO」から表示する。
- ウィジェットのカテゴリ見出しから表示し、対象カテゴリのタブを初期選択する。対象カテゴリが削除済みの場合はカテゴリ未設定へフォールバックする。
- TODO行のタップで、そのTODOの登録・編集画面へ移動する。
- フローティングボタンからTODOの新規登録画面へ移動する。
- ハンバーガーメニューから他の主要画面へ移動できる。
- 現在の画面と同じメニュー項目を選択した場合は、画面を重複して積まずドロワーだけを閉じる。

## 3. 画面構成

上から次の順に配置する。

1. タイトル「カテゴリ別TODO」とハンバーガーメニューを持つトップアプリバー
2. 横スクロール可能なカテゴリタブ
3. 選択カテゴリのTODO一覧または空状態
4. TODO追加用フローティングボタン
5. 固定バナー広告

コンテンツの最大幅は840dpとし、広い画面でも単一列を維持する。

## 4. カテゴリ選択

- 「カテゴリ未設定」を先頭に表示する。
- 登録済みカテゴリはカテゴリ管理画面の表示順で並べる。
- 全カテゴリを同時表示する「すべて」は設けない。
- タブをタップすると、そのカテゴリのTODOへ即時に切り替える。
- 選択カテゴリは画面の再生成後も保持する。
- 選択中のカテゴリが削除された場合は「カテゴリ未設定」へ戻す。

## 5. 表示対象と状態

- 選択カテゴリに属する非アーカイブTODOを、予定回へ展開せずTODO定義ごとに1行表示する。
- 開始日前、実施期間中、終了日経過後、無期限のTODOをすべて表示する。
- 今日の実行対象であるTODOには、未完了・完了・スキップのいずれの状態も省略せず表示する。
- 今日の実行対象でないTODOには状態ラベルを表示しない。
- 履歴上の過去の状態を行へ列挙しない。履歴確認はカレンダー履歴画面を使用する。
- 完全削除済みおよびアーカイブ済みTODOは表示しない。
- TODOは登録日時の昇順で安定して並べる。

## 6. TODO行

- タイトルを最大2行で表示する。
- 繰り返し方式または単発の開始日を補助情報として表示する。
- 今日の状態がある場合は、文言とアイコンを持つ状態ラベルで示し、色だけに依存しない。
- 状態ラベル領域は112dpの固定幅とし、今日の状態がないTODOでも同じ領域を維持する。
- 状態ラベルの有無や文言の長さによって、タイトルと補助情報の利用可能幅を変えない。
- 完了チェックボックス、スキップ、アーカイブ、削除などの操作メニューを表示しない。
- 行全体をタップ可能にし、該当TODOの登録・編集画面を開く。
- タップで状態を変更しない。

## 7. 状態別表示とフィードバック

- 初回読込中は進捗表示を行う。
- 選択カテゴリにTODOがない場合は「このカテゴリにTODOはありません」と表示する。
- 広告削除済み、同意未取得または広告読込失敗時は、空の広告領域を残さない。
- ドロワー表示中はバナー広告を一時的に非表示とする。

## 8. アクセシビリティと入力

- 選択中のカテゴリを選択状態として支援技術へ通知する。
- TODO行からタイトル、繰り返し方式、今日の状態を読み取れるようにする。
- タッチ、キーボード、マウス、TalkBackおよびスイッチアクセスでカテゴリ選択と行の遷移を行えるようにする。
- 文字サイズを拡大してもカテゴリタブとTODO行の操作対象を失わない。

## 9. 受け入れ条件

1. ハンバーガーメニューまたはウィジェットのカテゴリ見出しからカテゴリ別TODO一覧を独立画面として開け、外部導線では対象カテゴリを選択できる。
2. カテゴリ未設定と登録済みカテゴリを正しい順で表示し、選択を切り替えられる。
3. 選択カテゴリの非アーカイブTODOを全期間について定義ごとに1件表示できる。
4. 今日の未完了・完了・スキップTODOをすべて状態付きで表示できる。
5. 今日の実行対象でないTODOは、誤った当日状態を付けず表示できる。
6. TODO行に完了チェックや操作メニューがなく、行タップだけで編集画面へ遷移できる。
7. 行タップではTODO状態が変化しない。
8. 読込中、0件および広告非表示の各状態でレイアウトが破綻しない。
9. 選択中カテゴリの削除後にカテゴリ未設定へ安全にフォールバックする。
10. 画面再生成、各ウィンドウ幅、支援技術およびキーボード入力でも選択と遷移を継続できる。
11. 今日の状態ラベルの有無や種類が変わっても、TODO行のタイトルと補助情報の位置・幅を揃えられる。
