# ウィンドウ分類・ナビゲーション仕様

- 文書状態: 確定
- 最終更新日: 2026-08-10
- 親仕様: [画面サイズ・適応レイアウト仕様](README.md)

## 1. 最小対応領域

- 最小ウィンドウ幅は320dpとする。
- 最小ウィンドウ高さは320dpとする。
- 最小値未満では正常動作を保証しないが、クラッシュやデータ破損を発生させない。
- 水平方向へ画面全体をスクロールさせない。長い値は折り返し、省略、スクロール可能な入力欄を用途に応じて使用する。
- 高さが小さい場合は本文を縦スクロール可能にし、主要な確定・破棄操作へ到達できるようにする。

## 2. ウィンドウサイズクラス

### 2.1 幅

| クラス | 現在の幅 | 主な構成 |
| --- | --- | --- |
| Compact | 0～599dp | 単一ペイン、モーダルドロワー |
| Medium | 600～839dp | 単一ペイン、ナビゲーションレール |
| Expanded | 840～1199dp | 必要な画面を2ペイン化、ナビゲーションレール |
| Large | 1200～1599dp | 2ペイン、常設ナビゲーションドロワー |
| Extra-large | 1600dp以上 | 2ペイン、常設ナビゲーションドロワー、最大幅制限 |

境界値は小さい側を含まず、大きい側へ切り替える。たとえば600dpはMedium、840dpはExpandedとする。

### 2.2 高さ

| クラス | 現在の高さ | 扱い |
| --- | --- | --- |
| Compact | 0～479dp | 省スペース構成、モーダルドロワー、縦スクロール優先 |
| Medium | 480～899dp | 標準構成 |
| Expanded | 900dp以上 | 標準構成。余分な高さだけを伸長可能領域へ配分 |

幅がMedium以上でも高さがCompactの場合は、ナビゲーションレールまたは常設ドロワーを表示せず、モーダルドロワーを使用する。

## 3. 共通余白と最大幅

### 3.1 外側余白

| 幅クラス | 左右の最小余白 |
| --- | --- |
| Compact | 16dp |
| Medium | 24dp |
| Expanded | 32dp |
| Large / Extra-large | 48dp |

システムInsets、ディスプレイカットアウトまたはヒンジによって追加余白が必要な場合は、大きい方を使用する。

### 3.2 最大幅

- 入力フォームと設定一覧: 720dp
- 単一のTODO一覧、アーカイブ一覧、カテゴリ一覧: 840dp
- カレンダーと詳細を含む主要コンテンツ全体: 1200dp
- 最大幅を超える領域は中央配置し、余白として残す。
- 行の高さや文字サイズをウィンドウ幅に比例して拡大しない。

## 4. 2ペイン判定

2ペイン対応画面は、次をすべて満たす場合だけ2ペインにする。

1. 幅クラスがExpanded以上である。
2. 高さクラスがMedium以上である。
3. ナビゲーション領域、システムInsets、ヒンジおよび外側余白を除いた利用可能幅が736dp以上である。

- ペイン間隔は24dpとする。
- ヒンジがペイン境界を形成する場合、間隔はヒンジ領域を包含する。
- 2ペイン条件を満たさなくなった場合は、現在操作中または選択中の詳細側を優先して単一ペインへ移行する。

## 5. アプリ全体ナビゲーション

### 5.1 ナビゲーション形式

| 条件 | 形式 | 幅 |
| --- | --- | --- |
| 幅Compact、または高さCompact | ハンバーガーボタン＋Modal Navigation Drawer | 最大360dpかつウィンドウ幅の80%以下 |
| 幅Medium / Expanded、かつ高さMedium以上 | Navigation Rail | 80dp |
| 幅Large / Extra-large、かつ高さMedium以上 | Permanent Navigation Drawer | 240dp |

- Bottom Navigationは使用しない。
- ナビゲーション形式が変わっても、選択中の目的地と画面内状態を保持する。
- レールと常設ドロワーでは、トップアプリバーにハンバーガーボタンを表示しない。
- モーダルドロワーは外側タップ、戻る操作、Escapeで閉じる。

### 5.2 項目と選択状態

ナビゲーション項目と順序は画面仕様の定義を維持する。

- TODO一覧
- カレンダー
- カテゴリ管理
- アーカイブ済みTODO
- 設定

- 現在画面を選択状態で示し、色だけに依存しない。
- 項目選択後、モーダルドロワーは閉じる。
- 同じ項目を再選択した場合は画面を重複生成しない。
- レールはアイコンと日本語ラベルを常時表示する。
- 常設ドロワーはアイコンと日本語ラベルを表示し、折りたたみ操作は設けない。

## 6. トップアプリバー

- トップアプリバーの高さと操作順はデザインシステムに従う。
- 画面タイトルは利用可能幅で1行省略し、TalkBackには全文を提供する。
- 幅変更によって主要操作をメニューへ出し入れする場合も、操作の意味と順序を維持する。
- 2ペイン時も画面全体で1つのトップアプリバーを原則とし、ペインごとに重複表示しない。
