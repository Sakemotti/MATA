# MATA ドメイン仕様

- 文書状態: 初版
- 最終更新日: 2026-08-10

このフォルダでは、MATAのTODO、繰り返し、論理日、履歴をすべての画面・通知・ウィジェットで一貫して扱うためのドメイン仕様を管理する。

## 文書一覧

- [データモデル仕様](data-model.md)
  - Room、DataStore、エンティティ、型、制約、履歴スナップショット、マイグレーション
- [繰り返し計算仕様](recurrence-rules.md)
  - 論理日、期限、通常の繰り返し、週X回・月X回、祝日、計算エンジン
- [状態遷移・整合処理仕様](state-transitions.md)
  - 完了、スキップ、未完了確定、編集、アーカイブ、復元、再計算、長期未起動時の補完

## 位置付け

- [アプリ全体仕様](../app-spec.md)をドメイン実装へ落とし込む。
- [画面仕様](../screen-specs/README.md)から発生する操作を、状態遷移として定義する。
- UI、通知、ウィジェットは本フォルダで定義する同一の計算結果を利用し、独自の繰り返し判定を持たない。
- 通知配信、バックアップファイル、ウィジェット表示などの機能固有仕様は、それぞれの仕様書で本仕様を参照する。

## 共通原則

1. TODO定義と実行記録を分離する。
2. 未操作の現在・将来の予定を事前生成しない。
3. 確定済み履歴は後の編集や設定変更で書き換えない。
4. 現在と将来は同じ純粋なKotlin計算処理で再計算する。
5. 状態変更と整合処理は、再実行しても重複しない。
6. 日時計算では端末の現在タイムゾーンを使用し、確定した論理日は履歴へ固定する。
