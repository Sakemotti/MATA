# SCR-007 カテゴリ別TODO一覧 動作確認項目

- 対象仕様: [カテゴリ別TODO一覧画面仕様](../screen-specs/category-todo-list/spec.md)
- ID対応: `CTL-nnn`は受け入れ条件`nnn`へ1対1で対応する

| ID | 優先度 | 推奨種別 | 条件・操作 | 期待結果 | 結果 | 証跡・備考 |
| --- | --- | --- | --- | --- | --- | --- |
| CTL-001 | P0 | UI/E2E | 各主要画面のハンバーガーメニューとウィジェットのカテゴリ見出しから開く | 独立したカテゴリ別TODO一覧が開き、メニュー経由では同項目、ウィジェット経由では対象カテゴリが選択状態になる | 未実施 | |
| CTL-002 | P0 | UI/INT | カテゴリを並べ替え、カテゴリ未設定を含む各タブを選ぶ | カテゴリ未設定、ユーザー指定順のカテゴリが並び、選択したカテゴリへ一覧が切り替わる | 未実施 | |
| CTL-003 | P0 | INT/UI | 開始日前、実施期間中、終了済み、無期限のTODOを同じカテゴリへ登録する | アーカイブ以外を予定回へ展開せず定義ごとに1行表示する | 未実施 | |
| CTL-004 | P0 | INT/UI | 今日の未完了・完了・スキップTODOを同じカテゴリへ用意する | 3状態の行が省略されず、それぞれ文言とアイコンを持つ状態ラベルで表示される | 未実施 | |
| CTL-005 | P1 | UI | 今日が実行日でないTODOと開始日前TODOを表示する | TODO行は表示されるが当日の状態ラベルは表示されない | 未実施 | |
| CTL-006 | P0 | UI | 各状態のTODO行を確認してタップする | チェックボックスと操作メニューがなく、該当TODOの編集画面だけが開く | 未実施 | |
| CTL-007 | P0 | INT/UI | 行タップ前後のTODO状態と履歴を比較する | 編集画面への遷移だけが行われ、TODO状態と履歴は変化しない | 未実施 | |
| CTL-008 | P1 | UI | 読込遅延、0件、広告削除済み、広告読込失敗を順に再現する | 進捗と空メッセージを正しく表示し、広告非表示時に空領域を残さない | 未実施 | |
| CTL-009 | P0 | INT/UI | カテゴリを選択した状態でカテゴリ管理画面からそのカテゴリを削除して戻る | カテゴリ未設定へフォールバックし、削除カテゴリの古いTODOを表示しない | 未実施 | |
| CTL-010 | P1 | UI/MANUAL | 選択後に回転・プロセス再生成し、各幅でキーボードとTalkBackを使用する | 選択を保持し、カテゴリとTODO行を識別して編集画面へ遷移できる | 未実施 | |
