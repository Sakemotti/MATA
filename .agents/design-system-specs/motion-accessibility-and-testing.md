# モーション・アクセシビリティ・試験仕様

- 文書状態: 確定
- 最終更新日: 2026-08-10
- 親仕様: [MATAデザインシステム仕様](README.md)
- 関連仕様: [総合動作確認項目書](../test-specs/README.md)

## 1. モーション

### 1.1 基本方針

- Material 3コンポーネントの標準モーションを優先する。
- アニメーションは状態変化と画面構造の理解を補助する場合だけ使用する。
- 読み込み完了を待つためにアニメーション時間を延長しない。
- 点滅、連続回転、常時脈動する装飾を使用しない。
- 画面遷移はPredictive Backと競合しないようにする。
- 端末のAnimator Duration Scaleが0の場合はアニメーションを即時完了する。

### 1.2 時間Token

| Token | 時間 |
| --- | --- |
| `motionInstant` | 0ms |
| `motionFast` | 100ms |
| `motionShort` | 150ms |
| `motionMedium` | 250ms |
| `motionLong` | 400ms |

### 1.3 適用

- 押下、色、チェック状態の変化には100〜150msを使用する。
- 行の表示・非表示には200msを使用する。
- 画面間のFade Throughには250msを使用する。
- 400msを超える独自アニメーションを原則使用しない。
- 完了処理成功後、チェック状態を150msで切り替え、必要な場合は行を200msで除去する。
- 一括再計算後に大量の行を個別アニメーションさせない。

## 2. カテゴリ並べ替え

- ドラッグ開始時に対象行をElevation Level 3へ上げる。
- ドラッグ中の行を最大1.02倍へ拡大する。
- Elevationと拡大を150msで適用する。
- 周辺行の位置変更を200msでアニメーションする。
- ドロップ後はMedium相当のSpringで元の形状へ戻す。
- ドラッグ開始とドロップ成功時に、端末設定へ従った軽い触覚フィードバックを使用する。
- 並べ替え失敗時は元の位置へ戻し、Snackbarで通知する。
- アニメーション無効時は位置だけを即時変更する。

## 3. アクセシビリティ

### 3.1 コントラストと色

- 通常文字は背景とのコントラスト比4.5:1以上とする。
- 大きな文字と主要な非テキストUIは3:1以上とする。
- Materialの対応する`on`カラーとContainerカラーを組み合わせる。
- 色だけで状態、カテゴリ、選択、エラーを伝えない。

### 3.2 Semantics

- すべての操作へ役割、状態、日本語ラベルを設定する。
- 関連する行要素は意味の通る単位へSemanticsを統合する。
- 操作ボタンをTODO行全体のSemanticsへ誤って統合しない。
- 読み上げ順序を視覚的な情報順序と一致させる。
- 状態アイコンと操作アイコンを異なる役割として読み上げる。
- 読み込み、空状態、エラー、保存結果、Snackbarを必要に応じて通知する。

### 3.3 操作と拡大

- 視覚上のアイコンが48dp未満でもタップ領域は48dp以上確保する。
- フォントスケール200%と表示サイズ拡大をサポートする。
- 横方向のスクロールを必須にせず、文字拡大時は縦方向へリフローする。
- TalkBack操作中に自動的なフォーカス移動でユーザー操作を妨げない。
- アニメーション無効、色補正、色反転、ダークテーマで確認する。

## 4. 実装検査

- 共通テーマとコンポーネントのPreviewをライト、ダーク、固定テーマ、フォント拡大で用意する。
- 画面コードにハードコードされた色、文字サイズ、角丸、Elevationを追加しない。
- MaterialTheme外の意味トークンを直接ARGB値で参照しない。
- 共通コンポーネントにアクセシビリティSemanticsの既定値を持たせる。
- 実験的Material APIの追加時は、利用箇所、理由、置換条件を記録する。

## 5. 視覚・操作試験

### 5.1 テーマ

- 全画面を固定ライトテーマと固定ダークテーマで確認する。
- Android 12以上で複数のDynamic Colorパレットを確認する。
- Android 11以下で固定テーマへのフォールバックを確認する。
- テーマ変更が再起動なしで全画面、ダイアログ、ウィジェットへ反映されることを確認する。

### 5.2 色と状態

- 16カテゴリ色をライト・ダークテーマで確認する。
- 各カテゴリ色の前景アイコンと選択チェックを識別できることを確認する。
- 未完了、進行中、完了、スキップ、未達成、期限超過、未来、終了済みを比較する。
- カレンダーの日状態と期間結果を色なしでも識別できることを確認する。
- コントラスト比を自動検査と目視確認の両方で検証する。

### 5.3 文字と支援技術

- フォントスケール200%で全共通コンポーネントを確認する。
- 最大表示サイズで主要情報と操作が欠けないことを確認する。
- TalkBackでラベル、役割、状態、読み上げ順序、操作結果を確認する。
- 色補正、色反転、ダークテーマで状態を識別できることを確認する。

### 5.4 モーション

- Animator Duration Scale 0、0.5、1、2で確認する。
- 完了、行除去、画面遷移、カテゴリ並べ替えが指定時間と順序で動作することを確認する。
- 大量再計算時に行ごとの過剰なアニメーションが発生しないことを確認する。
- Predictive Back中に独自画面遷移が競合しないことを確認する。

### 5.5 回帰

- ライト、ダーク、固定テーマのスクリーンショット回帰テストを作成する。
- Dynamic Colorは代表的な制御済みColorSchemeを注入して回帰テストする。
- Materialライブラリ更新時に全共通コンポーネントのスクリーンショットを再比較する。
- ハードコードされたデザイントークンが画面コードへ追加されていないことをレビューする。

## 6. 受け入れ条件

1. 状態変化、行表示、画面遷移を定義済みの時間Tokenで表現できる。
2. アニメーション無効時にすべての状態を即時確定できる。
3. カテゴリドラッグ中のElevation、拡大、移動、触覚フィードバックを仕様どおり提供できる。
4. 文字と主要な非テキストUIが必要なコントラスト比を満たす。
5. 色を除いても状態、カテゴリ、選択、エラーを識別できる。
6. TalkBackで画面情報と操作を意味の通る順序で利用できる。
7. フォントスケール200%と最大表示サイズで主要情報と操作が欠けない。
8. ライト、ダーク、固定テーマの視覚回帰を自動検出できる。
9. Material更新後の共通コンポーネント差分を確認できる。
10. 画面固有コードに未承認のハードコード値を追加しない。
