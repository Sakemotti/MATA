# SCR-003 カレンダー履歴画面仕様

- 文書状態: 未策定
- 関連仕様: [アプリ全体仕様](../../app-spec.md)

## 目的

日付ごとのTODO実施状況をカレンダーから振り返る画面とする。

## 現時点で確定している範囲

- カレンダーの日ごとに完了数と予定数を表示する。
- 日付を選択すると、その日の完了、未完了、スキップのTODOを確認できる。
- 週X回・月X回では、完了日と期間終了時の達成結果を確認できる。
- アーカイブ済みTODOの履歴も表示する。
- 有効期間内の完了は取り消せる。
- 過去の有効期間に属する履歴は変更できない。

## 詳細仕様

月・週の移動方法、日セルの表現、選択日の履歴表示、状態の色分け、履歴からの遷移などを今後策定する。
