## 1. 変更範囲

- [PR #308](https://github.com/Sakemotti/MATA/pull/308): 過去TODO詳細・アーカイブ履歴詳細・カテゴリ編集のカード、区切り、下部ボタンを統一する。
- [Issue #309](https://github.com/Sakemotti/MATA/issues/309) / [PR #312](https://github.com/Sakemotti/MATA/pull/312): ドロワーと今日の一覧から開く未完了TODO一覧、TODO単位のカード・カテゴリ絞り込み・過去分のページ表示、今日への再登録と今回分の一覧除外を追加する。
- 再登録は入力済みの初期値を変更せず保存できる。新しいTODOを1件だけ作り、元の今回分の除外と同時確定する。キャンセル・失敗時は元の状態を変えない。
- 一覧除外は履歴、今日の通常一覧、ウィジェットを変更せず、新しく発生した未完了は再表示する。
- Roomは8→9、バックアップ形式は5→6へ移行する。旧形式1〜5を復元できるが、形式6を旧アプリで復元することはできない。ダウングレードせず、更新前のバックアップを安全な場所へ残す。
- 権限・外部SDK・データ収集の追加はない。生成後にManifest・SBOM・署名を前版と照合する。

## 3. 生成とGoogle Play登録

1. バージョン設定PRとCIを確認してmainへマージし、クリーンなmainからUpload Key署名済みAABを生成する。
2. 単一署名者・証明書SHA-256・Application ID・versionCode・最適化・Manifest・SBOM・5成果物のハッシュとRelease事前検査を確認し、生成元commitとともに候補生成結果へ記録する。生成済みを公開済みと扱わない。
3. 「テストとリリース → テスト → クローズド テスト」から現在の新トラックを開き、新しいリリースへ検証済みのAABだけを登録する。保管用ZIPをアップロードしない。
4. 解析結果が`com.mochisofts.mata` / `1.0.0` / `10`であること、テスター・地域設定と警告を確認する。既知のネイティブシンボル警告も今回の実際の表示を記録する。
5. リリース名を`1.0.0 (10) Additional closed testing`とし、第2節を登録してClosed testingへ公開する。Productionへ自動昇格しない。
6. 公開日時・正確な状態文言・警告・SDK Index・ポリシー・App content・AdMob・Pre-launch reportの状態を記録する。未確認・レポート未生成を合格としない。

ダッシュボードの案内カードは初期トラックを参照するため、トラック管理は専用ページを使う。トラックやテスター設定を作り直したり、再オプトインを求めたりしない。
