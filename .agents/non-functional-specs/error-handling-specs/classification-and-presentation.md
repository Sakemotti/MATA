# エラー分類・表示仕様

- 文書状態: 確定
- 最終更新日: 2026-08-10
- 親仕様: [エラー処理・障害回復仕様](README.md)

## 1. エラー分類

| 分類 | 例 | 基本表示 | 基本操作 |
| --- | --- | --- | --- |
| 入力エラー | 必須、文字数、範囲、重複 | 入力欄直下 | 該当欄を修正 |
| 業務ルールエラー | 過去日登録、期間外取消 | 入力欄またはSnackbar | 内容を修正・閉じる |
| 競合・対象消失 | 他処理で編集、復元、削除済み | Snackbarまたは画面状態 | 最新状態を表示 |
| 一時的な端末内エラー | 保存失敗、空き容量不足 | Snackbarまたはダイアログ | 再試行 |
| 初期取得エラー | 一覧・詳細を表示できない | 画面内エラー状態 | 再試行・戻る |
| 通信エラー | 祝日、UMP、広告 | 非遮断メッセージ | 再試行・基本機能継続 |
| OS権限・設定不足 | 通知権限、正確なアラーム | 説明付き状態 | システム設定を開く |
| 長時間処理エラー | バックアップ、復元 | 結果ダイアログ | 再実行・保存先確認 |
| データ整合性エラー | DB破損、移行失敗 | 遮断エラー画面 | 再起動・復元案内 |
| 予期しないエラー | 未分類例外 | 安全な共通文言 | 再試行・アプリ再起動 |

## 2. 表示手段

### 2.1 入力欄

- 修正対象が特定できる入力エラーは、該当欄の直下へ表示する。
- 保存操作時は最初のエラー欄へスクロールしてフォーカスを移す。
- 入力を修正して条件を満たした時点でそのエラーを解除する。
- 複数欄にまたがる期間不整合は、関係する欄の近くへ共通メッセージを表示する。

### 2.2 Snackbar

- 現在の内容を維持できる操作失敗と短い完了通知に使用する。
- 再試行可能ならアクションを「再試行」とする。
- 破壊的操作に対する「元に戻す」は各画面仕様で認められた場合だけ表示する。
- 同じ原因のSnackbarを連続表示せず、表示中は新しい同種イベントへまとめる。

### 2.3 画面内エラー

- 初回取得に失敗し、主要内容を表示できない場合に使用する。
- 画面タイトルとナビゲーションは維持する。
- 簡潔な説明、「再試行」、必要に応じて「戻る」を表示する。
- 装飾イラストは必須とせず、操作とメッセージを優先する。

### 2.4 ダイアログ

- データ整合性障害、復元失敗など、見落とすと重大な場合に使用する。
- 単純な通信失敗や入力誤りにダイアログを乱用しない。
- ダイアログ外タップで閉じると影響を理解できない場合は、明示ボタンで閉じる。

### 2.5 継続的な状態

- 通知権限、正確なアラーム、祝日情報のように継続する問題は、関係する設定行または画面内へ状態として表示する。
- 一度消えるSnackbarだけを唯一の通知手段にしない。

## 3. 文言

- 日本語で、ユーザーが実行した対象を主語にする。例: 「TODOを保存できませんでした」。
- 原因を確定できない場合は断定しない。例: 「通信できませんでした。接続を確認して再試行してください」。
- データが変更されていない場合は、その旨を必要に応じて示す。
- 取り消せない影響は操作前の確認に示し、失敗後の文言だけに依存しない。
- 「エラーが発生しました」だけで終わらせず、少なくとも再試行、戻る、設定確認のいずれかを示す。
- エラーコードを表示する場合は問い合わせ用の短い診断IDだけとし、個人情報を符号化しない。

## 4. 代表文言

| 状況 | 文言 | 操作 |
| --- | --- | --- |
| 保存失敗 | TODOを保存できませんでした。内容は保持されています。 | 再試行 |
| 完了失敗 | 完了にできませんでした。最新の状態に戻しました。 | 再試行 |
| 対象消失 | TODOが見つかりません。 | 一覧へ戻る |
| オフライン | 通信できませんでした。端末内の機能は引き続き利用できます。 | 再試行 |
| 容量不足 | 端末の空き容量が不足しているため保存できませんでした。 | 閉じる |
| 初期取得失敗 | データを読み込めませんでした。 | 再試行 |
| DB利用不可 | データを安全に開けませんでした。再起動しても直らない場合はバックアップからの復元が必要です。 | アプリを終了 |
| 予期しない失敗 | 処理を完了できませんでした。もう一度お試しください。 | 再試行 |

画面固有の確定済み文言がある場合は画面仕様を優先する。

## 5. アクセシビリティ

- 入力エラーはエラー状態と関連付け、TalkBackから項目名と一緒に読み上げられるようにする。
- 新しい遮断エラーまたは処理結果はライブリージョン等で一度通知する。
- Snackbarだけにフォーカスを強制移動しない。
- エラー、警告、成功を色だけで区別しない。
- 再試行ボタンは何を再試行するか識別可能なセマンティクスを持つ。
- 画面回転やサイズ変更後に同じエラーを重複して読み上げない。
