# 法的サイト公開・同期運用仕様

- 文書状態: 確定
- 最終更新日: 2026-09-02
- 親仕様: [法的文書仕様](README.md)
- 関連文書: [法的サイト原稿](../../../legal-site/README.md)、[リリースチェックリスト](../release-specs/release-checklist.md)

## 1. 正本と公開先

- 本リポジトリの`legal-site`を、法的文書、トップページ、サイトマップ、robotsおよび`app-ads.txt`の正本とする。
- 別途設定済みのGitHub Pages公開リポジトリは配信用コピーとし、公開リポジトリだけで本文を変更しない。
- 公開URLは`https://mochisofts.com/`配下とし、アプリの設定画面も同じURLを開く。
- 公開リポジトリへのコピー、commitおよびpushはユーザーが手動で行う。

## 2. 通常の変更手順

1. 本リポジトリで法的仕様と`legal-site`のHTMLを同じブランチ上で変更する。
2. 制定日・改定日、アプリ実装、Google Play申告、Data safety、UMPおよび問い合わせ先との整合を確認する。
3. `node legal-site/verify.mjs`を実行し、Pull Requestの全CIを成功させる。
4. Pull Requestを本リポジトリの`main`へマージし、正本側commit SHAを記録する。
5. ユーザーがマージ済み`legal-site`の中身を公開リポジトリのルートへコピーする。
6. 公開リポジトリの差分が意図した法的サイト変更だけであることを確認し、commit・pushする。
7. GitHub Pagesのデプロイ完了後、変更対象を含む公開URLを認証なしで開く。
8. アプリの設定画面からプライバシーポリシーと利用規約を開き、公開した最新版が表示されることを確認する。
9. 正本側commit SHA、公開側commit SHA、公開確認日時、確認URLおよび確認者をリリース記録へ残す。

## 3. 公開時の禁止事項

- 本リポジトリへマージする前に公開リポジトリだけを更新しない。
- 公開リポジトリで文言を直接修正し、本リポジトリへ反映しない状態を作らない。
- 未確定の個人情報、秘密情報、広告ユニットID、署名情報またはアクセストークンをコピーしない。
- `app-ads.txt.example`のプレースホルダーを`app-ads.txt`として公開しない。
- GitHub Pagesのデプロイ完了と公開URLの内容を確認せず、Google Play申請やアプリ公開へ進まない。

## 4. 差異を発見した場合

- 公開リポジトリだけに差異がある場合は公開作業を停止し、本リポジトリの正本を基準に原因を確認する。
- 正当な修正が必要な場合は本リポジトリへ変更を戻し、通常の変更手順を最初から実施する。
- 誤公開により利用者への影響がある場合は公開内容を安全な確定版へ戻し、影響範囲、公開時間、対応commitおよび再発防止策を記録する。
