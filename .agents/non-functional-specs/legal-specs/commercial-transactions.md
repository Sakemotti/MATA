# 特定商取引法に基づく表記仕様

- 文書状態: 方針確定・公開前原稿・専門家確認必須
- 最終更新日: 2026-09-01
- 公開URL: `https://mochisofts.com/mata/commercial-transactions`
- 公開用HTML: `legal-site/mata/commercial-transactions/index.html`

## 1. 対象

Androidアプリ「MATA」内でGoogle Playを通じて提供する非消費型アプリ内商品`remove_ads`を対象とする。Google Playが決済処理を行うことだけを理由に、販売主体としての表示義務や問い合わせ対応がなくなるとは扱わない。

## 2. 販売者情報の請求時開示

個人運営者の戸籍上の氏名、住所および電話番号は公開リポジトリへ登録せず、消費者からの請求時に遅滞なく電子メールで提供する方式を採用する。

- 公開ページに、省略した事項を請求により遅滞なく提供することを明記する。
- 請求先は`com.mochisofts@gmail.com`とし、件名「特定商取引法に基づく表示事項の開示請求」を案内する。
- 氏名、住所、電話番号の開示請求に、利用者のTODO、購入トークン、注文IDまたは本人確認書類の添付を要求しない。
- 購入申込みの意思決定前に十分な時間をもって回答できる運用を用意する。
- 実際の氏名、活動住所、確実に連絡できる電話番号を安全な非公開記録で管理する。
- この方式がMATAの販売形態で適法か、本番公開前に専門家へ確認する。

## 3. 公開する販売条件

| 項目 | 表示内容 |
| --- | --- |
| 販売事業者・運営責任者 | 請求により遅滞なく電子メールで開示する旨と請求方法 |
| 所在地・電話番号 | 請求により遅滞なく電子メールで開示する旨と請求方法 |
| 屋号 | Mochisofts |
| メールアドレス | `com.mochisofts@gmail.com` |
| 販売価格 | Google Playの購入確認画面に表示される価格。日本向け初期基本価格は500円（税込）だが、実際の請求額はGoogle Playの表示を優先する。 |
| 販売価格以外の必要料金 | インターネット接続および通信に必要な料金は利用者負担。 |
| 支払方法・時期 | Google Playで利用可能な支払方法と、Google Playが示す課金時期。 |
| 提供時期 | Google Playで購入済み状態を確認後、原則として直ちに広告削除を適用する。保留中は支払完了後に適用する。 |
| 商品内容 | 非消費型アプリ内商品`remove_ads`。MATA内の広告を削除し、定期購入ではない。 |
| 申込数量・有効期間 | 同じGoogle Playアカウントにつき1件。購入権利が有効な間は期限を設けない。 |
| 動作環境 | Google Playのストア掲載に示す対応Android端末およびOS。 |
| キャンセル・返品・払い戻し | デジタル商品のため物理的な返品はない。キャンセルと払い戻しはGoogle Playの方針と適用法令に従い、法令上の権利を一律に排除しない。 |
| 権利の復元・終了 | 同じGoogle Playアカウントで有効な購入を確認できる場合に復元する。払い戻し、取消等で購入を確認できなくなった場合は広告削除を終了する。 |

## 4. 公開前確認

- Google Play Consoleの商品ID、価格、税表示、販売地域および商品説明と一致させる。
- 請求時開示の案内が購入前に容易に到達できることを確認する。
- 請求対応の担当者、回答期限、開示用テンプレートおよび安全な記録方法を準備する。
- 払い戻し文言をGoogle Playの現行方針と適用法令へ一致させる。
