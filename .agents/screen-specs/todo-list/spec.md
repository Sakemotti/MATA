# SCR-001 TODO一覧画面仕様

- 文書状態: 未策定
- 関連仕様: [アプリ全体仕様](../../app-spec.md)

## 目的

今日実行すべきTODOを確認し、完了やスキップなどの日常的な操作を行うための中心画面とする。

## 現時点で確定している範囲

- 日付ごとの表示とカテゴリごとの表示を切り替えられる。
- 完了済みTODOの表示・非表示を切り替えられる。
- 初期状態では完了済みTODOを表示しない。
- TODOは期限順で自動的に並べる。
- 期限超過状態を区別して表示する。
- TODOの完了、スキップ、完了の取り消しを行える。
- TODO登録・編集画面へ移動できる。

## 詳細仕様

画面構成、日付移動、カテゴリ表示、TODO行の情報量、操作方法、空状態、広告位置などを今後策定する。
