- 文書状態: 確定
- 最終更新日: 2026-08-26
- 親仕様: [MATAデザインシステム仕様](README.md)
- 関連仕様: [TODO一覧画面仕様](../../screen-specs/todo-list/spec.md)、[カレンダー履歴画面仕様](../../screen-specs/calendar-history/spec.md)、[アーカイブ済みTODO一覧画面仕様](../../screen-specs/archived-todos/spec.md)、[カテゴリ管理画面仕様](../../screen-specs/category-management/spec.md)

## 1. アイコン

- UIアイコンはMaterial Symbols Roundedを基調とする。
- 既存仕様のMaterial Icons IDと安定したアプリ内アイコンIDの対応表を持つ。
- 選択状態または完了状態ではFilled、通常状態ではOutlinedを使用してよい。
- 同じ操作に複数の異なるアイコンを使用しない。
- 絵文字を操作アイコンとして使用しない。
- 使用するアイコンだけをVector DrawableまたはCompose Vectorとして同梱する。
- アイコンだけのボタンには日本語のアクセシビリティラベルを必須とする。
- 装飾だけのアイコンはアクセシビリティツリーから除外する。
- 状態アイコンと操作アイコンの読み上げ役割を区別する。

## 2. アプリアイコン

- Adaptive Iconに対応する。
- 背景色はMATA Green `#386A20`とする。
- 前景は、繰り返しを表す円形矢印と完了を表すチェックを組み合わせた白いシンボルとする。
- アイコン内に「MATA」などの文字を入れない。
- カレンダー日付、チェックボックスだけ、同期アイコンだけに見える表現を避ける。
- AndroidのAdaptive Icon Safe Zone内へ主要シンボルを収める。
- 丸形、角丸四角、Squircleへのマスクで欠けないようにする。
- Android 13以降のThemed Icon用Monochrome Layerを提供する。
- Play Store用512pxアイコンも同じシンボルを使用する。
- SplashScreenには同じAdaptive Iconを使用し、背景にはテーマの`surface`を使用する。

## 3. 基本コンポーネント

| 用途 | コンポーネント |
| --- | --- |
| 主要操作 | Filled Button |
| 補助操作 | Filled Tonal ButtonまたはOutlined Button |
| 低優先度操作 | Text Button |
| 破壊的操作 | エラー色のText ButtonまたはOutlined Button |
| 入力 | Outlined Text Field |
| 一覧の選択・絞り込み | Filter Chip |
| 単一選択 | Radio Button |
| オン・オフ | Switch |

- Materialコンポーネントの役割と異なる操作を割り当てない。
- プレースホルダーだけで項目名を表現せず、常時識別できるラベルを表示する。
- 必須、任意、エラー、文字数をSupporting Textで表示する。
- 破壊的操作の確定だけにエラー色を使用し、取消操作には使用しない。

## 4. TODO行

- 基本背景は`surface`または`surfaceContainerLow`とする。
- 期限超過だけで行全体の背景色を変更しない。
- 完了ボタン、タイトル、期限、カテゴリ、状態ラベルの視覚的優先順位を保つ。
- 完了済みタイトルには取り消し線を使用する。
- 完了済みでも文字コントラストを過度に下げない。
- カテゴリは名前と色付きアイコンを併用する。
- 行全体のタップと完了ボタンのタップ領域を重複させない。
- 操作メニューは標準の縦三点アイコンを使用する。
- 未来、終了済み、読み取り専用は状態ラベルと操作可否の両方で表す。

## 5. カレンダー

- 選択日は`primaryContainer`と`onPrimaryContainer`で表示する。
- 今日には`primary`の輪郭を表示する。
- 選択日と今日が同じ場合は、塗りつぶしと輪郭を併用する。
- 操作不能日は文字色、Semantics、操作可否で区別する。

### 5.1 日全体の状態

| 状態 | アイコン | 色 |
| --- | --- | --- |
| 進行中 | `Schedule` | 進行中Role |
| 完了 | `CheckCircle` | 成功Role |
| 未達成 | `Error` | エラーRole |

### 5.2 期間結果

- 期間達成マーカーには小型の`CheckCircle`を使用する。
- 期間未達成マーカーには小型の`Error`を使用する。
- 期間マーカーは日全体の状態を上書きせず、別位置に表示する。
- マーカーへ「期間達成」「期間未達成」の読み上げ情報を設定する。
- 小型マーカー自体をタップ対象にしない。

## 6. 空・読み込み・エラー

### 6.1 空状態

- 代表アイコン、短い見出し、説明、必要な場合だけ主要操作で構成する。
- 空状態イラストは必須としない。
- 読み込み中に空状態を一時表示しない。

### 6.2 読み込み

- 初回画面読み込みには中央配置のCircular Progress Indicatorを使用する。
- 画面の一部更新には該当領域内の小型進捗またはLinear Progress Indicatorを使用する。
- Shimmer表現は使用しない。

### 6.3 エラー

- 取得エラーは該当領域内に説明と「再試行」を表示する。
- 入力エラーは入力欄直下へ表示する。
- 操作エラーは原則Snackbarで表示する。
- エラーコード、スタックトレース、外部SDKの生メッセージを表示しない。
- エラー状態でも入力済み内容と安全に利用できる操作を維持する。

## 7. Snackbar

- 画面内で同時に1件だけ表示する。
- 通常メッセージは4秒間表示する。
- 「元に戻す」を含むSnackbarは既存仕様どおり5秒間表示する。
- ユーザー操作が必須なメッセージだけ期限なしを許可する。
- FAB、バナー広告、IME、システムナビゲーションと重ならない位置に表示する。
- 成功メッセージにはMaterial 3標準表現を使用し、独自の成功色Snackbarを設けない。
- 破壊的操作や失敗時だけ必要に応じてエラー色を使用する。
- 表示内容をTalkBackへ通知する。

## 8. ダイアログとボトムシート

- 確認にはMaterial 3 Alert Dialogを使用する。
- 選択肢が多い場合はModal Bottom Sheetまたは全画面選択を使用する。
- 破壊的操作の確定ボタンだけエラー色を使用する。
- 「キャンセル」をエラー色にしない。
- タイトル、説明、影響範囲、確定・取消操作の順で表示する。
- 長文は本文領域だけをスクロール可能にする。
- 表示時は最初の意味のある要素へアクセシビリティフォーカスを移す。
- 背面コンテンツを操作できないようにする。
- 外側タップや戻る操作の可否は各画面の処理仕様に従う。

### 8.1 読み取り専用TODO詳細モーダル

- TODO一覧の過去TODO、カレンダー履歴、アーカイブ済みTODOの履歴詳細では、同じ共通コンポーネントを使用する。
- タイトル、説明、カテゴリ、呼び出し元に応じた詳細項目、「閉じる」の順で表示する。
- 説明が空の場合は「説明なし」、期限や通知など任意値がない場合は「設定なし」または各画面仕様で定めた表現を表示する。
- カテゴリは名称に加えて、保存されている色とアイコンを表示する。
- カレンダー履歴とアーカイブ履歴は、現在値ではなく履歴に保存された当時のスナップショットを表示する。
- 本文領域だけを縦スクロール可能にし、「閉じる」は本文の長さにかかわらず操作できるようにする。
- 編集、完了、完了取り消し、スキップ、アーカイブ、削除などの変更操作を置かない。
- システムの戻る操作とダイアログ外のタップで閉じられる。

## 9. 受け入れ条件

1. 同じ操作と状態で一貫したMaterialアイコンを使用できる。
2. Adaptive Icon、Themed Icon、Play Store用アイコン、SplashScreen用アイコンを同じブランド表現で用意できる。
3. 操作の優先度と破壊性に応じて正しいボタンを使用できる。
4. TODO行が期限超過、完了、未来、終了済みを色以外でも識別できる。
5. カレンダーの日状態と期間結果を別々に表示・読み上げできる。
6. 空、読み込み、取得エラー、入力エラー、操作エラーを区別できる。
7. Snackbar、FAB、広告、IME、システム領域が重ならない。
8. ダイアログとボトムシートをアクセシブルな順序で操作できる。
9. TODO一覧、カレンダー履歴、アーカイブ履歴から同じ構成の読み取り専用TODO詳細モーダルを表示できる。
