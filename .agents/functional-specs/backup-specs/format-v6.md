# MATA 手動バックアップ形式バージョン6

- 文書状態: 確定
- 最終更新日: 2026-10-18
- 対応Issue: #309

## 1. 変更内容

形式5を継承し、TODOの`carryOverEnabled`の直後へ`incompleteDismissedThroughDate`を追加する。値はISO日付文字列またはnullとし、通常のTODO定義・履歴とは独立した未完了一覧の確認済み境界を表す。回数型の現在期間では期間末日を識別日に使用するため、未来の日付を一律に不正扱いしない。

`formatVersion`と`minimumReaderVersion`は6とする。欠落や不正な日付を拒否し、形式1～5は境界をnullとして復元する。件数・ハッシュ・ZIP構造・上限・参照整合性・復元トランザクションは既存形式を継承する。古いアプリへ形式6を読み込ませない。

## 2. 試験

確認済み境界を持つTODOの書き出し・検証・復元、旧形式の移行、破損日付の拒否を確認する。非表示後の履歴・繰り返し・現在表示に影響しないことも確認する。
