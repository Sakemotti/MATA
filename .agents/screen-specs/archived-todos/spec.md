# SCR-005 アーカイブ済みTODO一覧画面仕様

- 文書状態: 未策定
- 関連仕様: [アプリ全体仕様](../../app-spec.md)、[カレンダー履歴画面仕様](../calendar-history/spec.md)

## 目的

今後の表示を停止したTODOを確認し、復元または完全削除する画面とする。

## 現時点で確定している範囲

- アーカイブ済みTODOを一覧表示する。
- TODOの内容と保持されている履歴を確認できる。
- TODOを復元できる。
- TODOとそのすべての履歴を完全削除できる。
- アーカイブ済みTODOの履歴もカレンダー履歴の集計と一覧へ含め、特別なラベルは表示しない。
- TODOを完全削除した場合は、カレンダー履歴から該当する日履歴と期間結果も取り除く。

## 詳細仕様

一覧の分類・並び順、詳細の表示方法、復元時の予定再開方法、削除確認、空状態などを今後策定する。
