# versionCode 6 Internal testing登録・更新確認手順

- 文書状態: 実施用
- 作成日: 2026-09-23
- 対象: MATA `1.0.0 (6)` 本番公開候補
- 目的: Closed testingの`1.0.0 (5)`から、同一データを保持したまま`1.0.0 (6)`へGoogle Play経由で更新できることを確認する

## 3. 登録前の確認

- [ ] 端末にはClosed testing版`1.0.0 (5)`がインストールされている
- [ ] アプリをアンインストールしていない
- [ ] TODO、カテゴリ、設定、完了履歴を更新前データとして用意した
- [ ] 手動バックアップを作成し、復元可能な場所へ退避した
- [ ] 更新前のアプリ情報、主要データ、設定を画面またはメモで記録した
- [ ] Internal testingの対象者へ、更新試験に使うGoogleアカウントを登録した
- [ ] ローカルAABのSHA-256が登録対象の固定情報と一致した

## 4. Google Play Consoleへの登録

1. MATAの「テスト」からInternal testingを開く。
2. 新しいリリースを作成する。
3. `mata-1.0.0-6.aab`だけをアップロードする。
4. 解析結果が`com.mochisofts.mata`、バージョン名`1.0.0`、バージョンコード`6`であることを確認する。
5. リリース名を`1.0.0 (6) Production candidate verification`とする。
6. 「リリースノート」に次の内容を登録する。

```text
MATAの初回リリースです。
毎日・曜日指定・月末・毎月第X曜日・N週間にX回・月X回など、柔軟な繰り返しTODOを管理できます。
今日の一覧、通知、ウィジェット、カレンダー履歴、カテゴリ分け、未完了TODOの繰り越し、手動バックアップに対応しています。
```

7. 新しいエラー、SDK警告、ポリシー警告がないことを確認する。
8. 既知の「ネイティブコードを含むがデバッグシンボル未登録」警告だけの場合は、警告内容を記録して継続する。
9. Internal testingとして公開する。Closed testingまたはProductionの既存リリースは変更しない。
10. 公開状態、公開日時、表示された警告を本書の実施記録へ転記する。

## 5. Google Play経由の上書き更新

1. 更新前の`1.0.0 (5)`を起動し、準備したデータが存在することを再確認する。
2. アプリをアンインストールせずに終了する。
3. Internal testing対象のGoogleアカウントでオプトインする。
4. Google PlayのMATAページに`更新`が表示されるまで待つ。
5. Google Playアプリ内のオプトイン画面で通信エラーになる場合は、同じGoogleアカウントでChromeからオプトインURLを開く。
6. `更新`を実行する。アンインストールやストレージ消去は行わない。
7. 更新後にMATAを起動し、アプリ情報が`1.0.0 (6)`であることを確認する。

表示の反映待ちと判断できる間は、アプリの再アップロードやリリースの作り直しを行わない。

## 6. 更新後の必須確認

- [ ] MATAがクラッシュせず起動する
- [ ] 更新前のTODO、カテゴリ、設定、完了履歴が保持されている
- [ ] 今日のTODO一覧が表示され、完了とスキップを操作できる
- [ ] TODOの登録、編集、アーカイブ、削除ができる
- [ ] 繰り返しTODOの対象日と回数が更新前後で不自然に増殖していない
- [ ] 通知が設定時刻どおりに届き、通知から状態を更新できる
- [ ] ウィジェットの一覧と完了・スキップ操作がアプリ本体へ反映される
- [ ] カレンダー履歴と集計が保持されている
- [ ] 手動バックアップを新規作成できる
- [ ] 広告が通常時に表示され、オフラインでも強制終了しない
- [ ] versionCode 6回帰試験実施票の未実施項目を完了した

詳細な確認対象と結果は[versionCode 6回帰試験実施票](version-6-regression-results.md)へ記録する。

## 7. 新規インストール確認

上書き更新に使用した端末とは別の端末またはテスト用プロファイルを使用する。

- [ ] Internal testingから新規インストールできる
- [ ] 初回起動が完了する
- [ ] 初期状態で不要な既存データが存在しない
- [ ] カテゴリ、TODOを登録して主要操作を完了できる
- [ ] 通知権限と広告同意の導線が正常に動作する

上書き更新のデータを消さないため、同一端末で新規インストール確認を行う必要がある場合は、バックアップと復元確認を完了してから実施する。
