# SCR-002 TODO登録・編集画面仕様

- 文書状態: 未策定
- 関連仕様: [アプリ全体仕様](../../app-spec.md)

## 目的

単発または繰り返しのTODOを新規登録し、既存TODOの内容を編集する画面とする。

## 現時点で確定している範囲

- タイトル、説明、カテゴリ、開始日、終了日または無期限、繰り返し、期限時刻、通知を入力できる。
- タイトルは必須とする。
- 1つのTODOには1種類の繰り返し方式を設定する。
- 編集内容は現在表示中のTODOにも即時反映する。
- 編集時はアーカイブまたは履歴を含む完全削除を行える。

## 詳細仕様

入力順、繰り返し方式ごとの入力UI、初期値、バリデーション、保存・破棄、削除・アーカイブ確認などを今後策定する。
