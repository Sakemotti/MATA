- [Issue #281](https://github.com/Sakemotti/MATA/issues/281) / [PR #285](https://github.com/Sakemotti/MATA/pull/285): ウィジェットをカード形式へ変更し、初回配置のプレビューを固定レイアウトにする。Android 15以降では以前の生成プレビューを削除し、ユーザーデータをプレビューへ表示しない。
- [Issue #284](https://github.com/Sakemotti/MATA/issues/284) / [PR #286](https://github.com/Sakemotti/MATA/pull/286): TODO一覧とカレンダー履歴の土曜日を青、日曜日・祝日を赤にする。土曜日と祝日が重なった場合は赤を優先する。祝日データの更新を画面へ反映し、読み込み失敗時も画面操作を継続する。

この更新ではSDK、DBスキーマ、バックアップ形式、権限および収集・共有データを変更しない。背景色設定を含むversionCode `7`の変更は維持する。
開発版の表示確認は完了しているが、Google Playから配布したversionCode `8`での再確認とは区別する。

## 4. Google Play Consoleへの登録

1. MATAのClosed testingで現在使用中のトラックを開く。
2. 新しいリリースを作成し、第1節のversionCode `8`のAABだけをアップロードする。ZIPやmappingはAAB欄へ登録しない。
3. 解析結果が`com.mochisofts.mata`、バージョン名`1.0.0`、バージョンコード`8`であることを確認する。
4. リリース名を`1.0.0 (8) Additional closed testing`とし、第2節のリリースノートを入力する。
5. 既存の対象国、テスター設定およびフィードバック経路を維持する。
6. エラー、SDK警告およびポリシー警告を確認する。既知のネイティブデバッグシンボル未登録警告だけの場合は記録して継続し、新規警告は個別に確認する。
7. Productionへ昇格せず、Closed testingの更新版として公開する。
8. 公開状態、公開日時、警告および各レポートの状態を第7節へ記録する。
