# MATA 手動バックアップ形式バージョン7

- 文書状態: 確定
- 最終更新日: 2026-11-13
- 対応Issue: #355

## 1. 変更内容

形式6の構造・項目順・ハッシュ・参照整合性・上限を継承し、`repeatType`へ`after_completion_days`を追加する。`repeatParams`は`{"intervalDays":N}`（Nは1～999）、`carryOverEnabled`は必須true、`dueDate`はnullとする。

`formatVersion`と`minimumReaderVersion`は7とする。形式6以下を対象とする旧アプリへ、新方式を含む可能性のあるバックアップを誤って読み込ませない。現行Readerは形式1～6を引き続き受理するが、それらの形式を名乗る`after_completion_days`は拒否する。

起点は完了・スキップ記録の`resolvedLogicalDate`から再構築し、別の起点や次回日の項目は追加しない。元の実行日、解決日、スナップショットと未解決の繰り越し状態は既存項目に保存する。復元時の整合処理で、日数分の未完了や未来の仮予定を生成しない。

## 2. 確認項目

- 新方式のTODO・間隔・強制繰り越し・完了／スキップ履歴が往復し、復元後の次回日が一致する。
- 形式1～6の受理を維持し、形式6の未完了一覧の確認済み境界を失わない。
- 間隔0・1000、繰り越しfalse、新方式を形式6以下として偽装した入力を、実データ変更前に拒否する。
- 起点がウィジェットの通常取得期間より前でも、復元後に直近の解決日から正しく表示・通知を再構築する。
