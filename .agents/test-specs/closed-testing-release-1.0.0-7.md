## 4. Google Play Consoleへの登録

1. MATAのClosed testingで現在使用中のトラックを開く。
2. 新しいリリースを作成し、本書に記録したversionCode `7`のAABだけをアップロードする。
3. 解析結果が`com.mochisofts.mata`、バージョン名`1.0.0`、バージョンコード`7`であることを確認する。
4. リリース名を`1.0.0 (7) Additional closed testing`とする。
5. 第2節のリリースノートを入力する。
6. 対象国、テスター設定およびフィードバック経路が既存リリースから維持されていることを確認する。
7. 新しいエラー、SDK警告またはポリシー警告がないことを確認する。
8. 既知のネイティブデバッグシンボル未登録警告だけの場合は、表示内容を記録して継続する。
9. Productionへ昇格せず、Closed testingの更新版として公開する。

## 5. versionCode 5から7への上書き更新

1. 更新前の`1.0.0 (5)`を起動し、準備したデータと設定を確認する。
2. アプリをアンインストールせずに終了する。
3. Closed testing対象アカウントでGoogle PlayのMATAページを開き、`更新`を実行する。
4. 更新後にMATAを起動し、versionCode `7`であることを確認する。
5. 起動、TODO、カテゴリ、履歴、設定、通知、ウィジェットおよび手動バックアップの状態が保持されていることを確認する。

Google Playアプリ内のオプトイン画面で通信エラーになる場合は、同じアカウントでChromeからオプトインURLを開く。
表示の反映待ちと判断できる間は、AABの再アップロードやリリースの作り直しを行わない。

## 6. versionCode 7の必須確認

### 6.1 フィードバック反映

- [x] ライトテーマの設定画面に背景色設定が表示される。
- [x] 標準を含む7候補を選択でき、選択した色がページ背景へ即時反映される。
- [x] カード、ダイアログおよび入力欄の色を不必要に上書きしない。
- [x] ダークテーマでは背景色設定が非表示になり、ライトテーマへ戻すと選択値が再適用される。
- [x] アプリ再起動後も選択値が保持される。
- [x] versionCode `7`で作成したバックアップから背景色を復元できる。
- [x] 旧形式のバックアップを復元した場合は標準背景色となる。

### 6.2 回帰確認

- [ ] 今日のTODO一覧、TODO登録・編集・完了・スキップ・削除を操作できる。
- [ ] 繰り返しTODOが不自然に増殖せず、通知が設定時刻どおりに届く。
- [ ] ウィジェットの一覧と完了・スキップ操作がアプリ本体へ反映される。
- [ ] カレンダー履歴、カテゴリ管理、アーカイブおよび設定を表示・操作できる。
- [ ] 広告が通常時に表示され、オフラインでも強制終了しない。
- [ ] クラッシュ、ANR、データ消失または意図しない初期化が発生しない。
