# 文字・形状・寸法仕様

- 文書状態: 確定
- 最終更新日: 2026-08-10
- 親仕様: [MATAデザインシステム仕様](README.md)

## 1. タイポグラフィ

### 1.1 フォント

- Android標準の`FontFamily.SansSerif`を使用する。
- 日本語表示には端末標準の日本語サンセリフフォントを使用する。
- アプリ独自フォントを同梱しない。
- 日本語へ不自然な文字間隔を設定しない。
- 英字を含めてボタン文字を全大文字へ変換しない。
- 本文へ斜体を使用しない。
- 状態の強調には過度な太字を使わず、MediumまたはSemiBoldまでとする。

### 1.2 Type Scale

Material 3標準Typographyを基準とし、主な用途を次のとおりとする。

| 用途 | Typography |
| --- | --- |
| 画面タイトル | `titleLarge` |
| ダイアログタイトル | `headlineSmall` |
| セクション見出し | `titleMedium` |
| TODOタイトル | `bodyLarge`、必要に応じてMedium相当 |
| 入力文字・本文 | `bodyLarge` |
| 説明・補助情報 | `bodyMedium` |
| 日時・カテゴリ補足 | `bodySmall` |
| ボタン | `labelLarge` |
| タブ・チップ | `labelLarge` |
| 状態ラベル | `labelMedium` |
| カレンダー補助表示 | `labelSmall` |

### 1.3 文字拡大

- 端末のフォントスケールと非線形スケーリングを尊重する。
- フォントスケール200%で主要情報と操作を欠落させない。
- テキストを含むコンテナへ固定高さを設定しない。
- 文字拡大時は横方向へはみ出さず、縦方向へリフローさせる。
- 省略表示は各画面仕様で明示されたタイトル・説明などに限定する。
- 省略したテキストもアクセシビリティサービスへ全文を提供する。

## 2. Shape Scale

| Shape | 角丸 |
| --- | --- |
| `extraSmall` | 4dp |
| `small` | 8dp |
| `medium` | 12dp |
| `large` | 16dp |
| `extraLarge` | 28dp |

- ボタン、チップ、FABなどはMaterial 3コンポーネントの既定形状を優先する。
- カードとTODOコンテナには`medium`を使用する。
- 小さな状態ラベルと入力補助には`small`を使用する。
- ダイアログとモーダルボトムシートには`extraLarge`を使用する。
- アイコン背景と完了ボタンには円形を使用する。
- 破壊的操作を角ばった形状だけで表現しない。

## 3. 余白

### 3.1 基準

- 4dpグリッドを基準とする。
- Compact幅の画面左右余白は16dpとする。
- セクション間は原則24dpとする。
- 関連するラベルと入力欄の間は8dpとする。
- 一覧行内の主要要素間は12dpとする。

### 3.2 Token

| Token | 値 |
| --- | --- |
| `spaceExtraSmall` | 4dp |
| `spaceSmall` | 8dp |
| `spaceMedium` | 12dp |
| `spaceDefault` | 16dp |
| `spaceLarge` | 24dp |
| `spaceExtraLarge` | 32dp |
| `spaceSection` | 48dp |
| `spaceHero` | 64dp |

## 4. サイズ

- タップ可能領域は最低48dp四方とする。
- 標準アイコンは24dpとする。
- 小さな非操作状態アイコンは18dpとする。
- カテゴリアイコンコンテナは32dp、内部アイコンは18dpとする。
- 空状態の代表アイコンは48〜64dpとする。
- 区切り線は1dpとし、文字やアイコンの開始位置へ揃える。
- 視覚上のアイコンが48dp未満でも、操作領域は48dp以上確保する。

## 5. Elevation

### 5.1 Level

| Level | 値 |
| --- | --- |
| 0 | 0dp |
| 1 | 1dp |
| 2 | 3dp |
| 3 | 6dp |
| 4 | 8dp |
| 5 | 12dp |

### 5.2 適用

- Material 3のTonal Elevationを優先する。
- 通常画面と一覧行は原則Level 0とする。
- スクロール後のトップアプリバーはLevel 2までとする。
- ナビゲーションドロワーはLevel 1とする。
- FABとドラッグ中の行はLevel 3とする。
- SnackbarとダイアログはMaterial 3の既定Elevationを使用する。
- 独自の濃い影や複数方向の影を使用しない。
- ダークテーマでは影よりTonal Elevationを優先する。

## 6. 受け入れ条件

1. すべての文字を共通Typographyから取得できる。
2. フォントスケール200%で主要情報と操作を維持できる。
3. 文字を含むUIが固定高さによって欠けない。
4. 形状、余白、サイズ、Elevationを共通トークンから取得できる。
5. すべての操作で最低48dpのタップ領域を確保できる。
6. ライト・ダークテーマでTonal Elevationを一貫して表示できる。
