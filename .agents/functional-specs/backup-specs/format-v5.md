# MATA 手動バックアップ形式バージョン5

- 文書状態: 確定
- 最終更新日: 2026-10-04
- 基底仕様: [バックアップ形式バージョン4](format-v4.md)

## 1. 適用範囲

バージョン5は、ライトテーマ用のページ背景色設定を追加した現行書き出し形式である。バージョン4のZIP構造、TODO、履歴、実行状態、正規順序、件数、ハッシュ、入力上限および参照整合性を継承する。

- `manifest.json.formatVersion`: `5`
- `manifest.json.minimumReaderVersion`: `5`
- `data.json.formatVersion`: `5`
- 読み込み側はバージョン1～5を受け付け、旧形式を現行モデルへ変換する。

## 2. settingsの変更

`settings.theme`の直後へ次のフィールドを追加する。

| フィールド | 型 | 値 |
| --- | --- | --- |
| backgroundColor | string | `default`、`ivory`、`light_green`、`light_blue`、`light_pink`、`light_purple`、`light_gray` |

- 値はライトテーマ用のページ背景色設定を表す。
- ダークテーマ中も選択値を失わず、そのまま書き出す。
- 一覧外の値は不正値として、現在データを変更する前に復元を拒否する。

## 3. 旧形式からの移行

- バージョン1～4には`backgroundColor`が存在しないため、`default`として復元する。
- 旧形式のテーマ、TODO、カテゴリ、通知、履歴およびその他の設定は変更しない。
- バージョン5の書き出しでは`backgroundColor`を省略しない。

## 4. 受け入れ条件

1. バージョン5で7種類の背景色設定を欠落なく往復できる。
2. バージョン1～4を背景色`default`として従来動作を維持して復元できる。
3. 未知の背景色コードをデータ変更前に拒否できる。
4. ダークテーマ中に作成したバックアップでも、保持中の背景色設定を復元できる。
5. バージョン5をバージョン4までにしか対応しない読込実装へ受け入れさせない。
